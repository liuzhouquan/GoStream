# WEB-UI：沉浸式浏览体验

基线：`main@29a3299`。分支：`feat/web-immersive-browse`。用户授权：2026-11-12，希望前端更接近成熟短视频产品。本轮为 v1.0 交付后的界面维护，保留原生 HTML/CSS/JavaScript 和现有业务API。

## 实现范围

- 深色侧栏、独立GoStream标识与SVG图标、清晰的搜索/发布/通知入口，移除外部字体依赖。
- 默认沉浸式舞台、逐条滚动吸附；保留网格并保存布局偏好。
- 可见视频静音自动播放，其他视频暂停；支持↑/↓切换、Space播放暂停、声音控制。输入框、按钮、原生视频控件和登录弹窗不被全局快捷键抢占。
- 页面切换和标签页隐藏时暂停播放；分页追加保留已有video节点，不重置当前播放器或重复登记其播放事件。
- 桌面评论抽屉、手机底部评论面板；等待响应时可关闭，迟到响应不重开；加载失败提供手动GET重试。Escape关闭并恢复触发按钮焦点。
- 手机五项底部导航，通知仍可从顶栏进入；390×844和桌面1440×900检查没有页面溢出。发布、资料、通知和聊天沿用真实表单并统一视觉。

未增加模型推荐、ABR/HLS、自定义聊天联系人业务或前端框架迁移。这些不是本轮显示层改造的前置条件。原Feed/MQ/IM/媒体持久化逻辑和既定性能验收范围不变。

4. `node --check web/app.js`、Python编译和 `git diff --check` PASS。没有为样式重复长A04/A10压测；最终head仍通过本PR的既有CI后合并，CI结果和合并SHA以PR记录为准。

首轮本地失败保留：新增body `data-view`与通用委托选择器冲突，造成点击误刷新；已改为`data-page`并限定导航匹配。截图另发现舞台高度叠加页边距造成页头上移，已改为固定视口的flex剩余高度。修正后重新执行上述回归。浏览器会话、临时服务和临时库按各runner的finally清理。

## 使用

按README启动后访问首页即可。右上角切换沉浸/网格；桌面舞台右侧按钮或↑/↓切片，Space暂停；视频初始静音，声音按钮用于开启。手机上下滑动切片，评论按钮打开底部面板。播放受浏览器策略限制时保留手动播放入口。
