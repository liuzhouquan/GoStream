## 4. 缺陷与边界记录

1. **历史遗留缺陷**：分支审查历史中曾记录 `openapi.yaml` 存在 `active` 误写为 `liked`/`favorited`、`User` 扁平与包装结构混淆、`last_seen` 与 `last_seen_at` 命名偏差等问题；
2. **本轮修正**：
   - 发现并修正 `Comment.parent_id` 缺失 `nullable: true` 导致 kin-openapi 解析顶级评论时报错的问题；
   - 发现并修正 `/api/users/{id}/videos` 错误引用 `VideoCard` Schema 导致非 Feed 查询缺失 `liked`/`favorited` 报错的问题；
   - 发现并补充所有受保护路由的 `401 Unauthorized` 契约定义；
   - 发现并纠正 `POST /api/messages/acks` 请求体字段为 `ids`（原测试偶发误写为 `message_ids`）；
   - 修正 `tools/` 辅助脚本在多 `package main` 下引发的 `go vet ./...` 冲突，添加 `//go:build ignore` 标签，实现包级检查与单文件运行的双向兼容。
