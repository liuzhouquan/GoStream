## 2. 范围、不变量与依赖

- **实现范围**：
  1. `tools/ffprobe_shim.py`：
     - 提供跨环境自适应的 `ffprobe` 兼容垫片。当系统未安装独立 `ffprobe` 命令行工具时，自动调用 `ffmpeg -i` 解析流属性，并格式化输出为 GoStream `probeVideo`/`parseVideoProbe` 所需的标准 JSON（包含 `streams[0].width`、`height`、`duration` 及 `format.duration`）；遇到损坏载荷时返回非零退出码。
  2. `tests/integration/media_matrix_smoke.py`：
     - 自动化生成 10 类可复现短视频测试夹具（MP4、WebM、MOV、有音轨/无音轨、H.264、VP8、VP9、ProRes、竖屏 360x640、超长超限、损坏载荷、>4 MiB 大分片）。
     - 支持 `--mode {auto,sqlite,compose}`，双 API 跨实例分发分片与查询。
     - 逐文件采集并核验：输入容器、编解码、分辨率、时长、源字节、终态、错误码、处理耗时、产物视频字节、封面字节。
     - 严格验证未发布（`failed`）视频的隐私边界：匿名与非作者访问 `GET /api/videos/{id}` 均 404；非作者查看作者公开视频列表自动过滤；公共搜索与公共 Feed 均排除；仅作者携带 Token 可见 `processing_error`。
     - 验证作者修复恢复（Recovery）：非作者 PATCH 拒绝 403；作者上传新媒体后通过 `PATCH /api/videos/{id}` 提交 `media_url`，状态重入 `processing` 并重新转码为 `published`，生成封面并上架公共 Feed。
     - 验证 >4 MiB 大视频跨实例分片续传与组装（API A 上传分片 0，API B 上传分片 1，API B 完成组装，核验 SHA-256 与幂等重试）。
  3. `tests/diagnostics/test_media_matrix.py`：
     - 7 个单元测试，覆盖 FFprobe 兼容垫片、损坏文件拦截、十视频规格定义、常量校验与报表结构序列化。
  4. 文档同步更新：
     - 更新 `docs/MEDIA_OPERATIONS.md`，记录十视频实测数据、隐私断言与恢复操作规范。
- **必须保持的不变量**：
  - 只有处于 `published` 状态的视频才能进入公共 Feed 和搜索。
  - 失败分片不持久化，上传会话幂等。
  - 租约只由当前持有者完成，孤儿清理不误删被引用的资产。
  - 失败视频的失败原因仅作者可见，不向未授权用户泄露元数据。
  - 不臆造转码吞吐数据，指标需有真实量测记录。
- **依赖任务**：G02（最终联合验收栈提供真实 MySQL 与 MinIO 双 API 容器环境）。
